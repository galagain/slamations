# Méthodes

Les 24 dossiers d'origine sont conservés. Depuis la racine, utiliser `./slam list`
pour voir les pipelines avec build/lancement TUM et les composants documentés.
Les commandes sont détaillées dans [le guide de démarrage](../README.md) et
[les ressources Docker](../RUNTIME.md).

Chaque méthode conserve ses scripts, Dockerfiles et patches existants.
Les résultats et campagnes historiques sont exclus. Les README individuels sont
les notes d'origine et peuvent mentionner des variantes ou résultats non exportés.
